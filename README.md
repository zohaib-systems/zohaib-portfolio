# Zohaib Portfolio

Production-style personal portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Local Development

```bash
npm install
npm run dev
```

## Build and Validate

```bash
npm run lint
npm run build
```

## Project Structure

- `/src/components` – portfolio sections (Hero, Projects, About, Skills, Services, Contact, Chatbot)
- `/src/assets` – static assets used in the app
- `/public` – public static files
